## ✒️ About
This repository contains my practice work while learning R programming. It focuses on building a strong foundation in R through regular coding practice, problem solving, and practical examples.

## 🎯 Goals
* Build a strong foundation in R programming
* Improve logical thinking and problem solving skills
* Practice writing clean and structured code
* Develop basic data analysis skills
* Maintain a consistent record of my learning progress

## 🛠️ Tools and Technologies
* **IDE:** RStudio [Posit Open Source](https://posit.co "RStudio desktop download")
* **Version Control:** Git [Git SCM](https://git-scm.com "Git Version Control System") & GitHub [GitHub](https://github.com/ "GitHub Platform")

## 📝 Topics Covered
* **R Fundamentals:** Basic syntax, setup, and working environment.
* **Variables and Data Types:** Understanding numeric, character, logical, and complex types.
* **Operators and Expressions:** Arithmetic, relational, and logical operations.
* **Control Flow:** Conditional statements (if-else) and loops (for, while).
* **Functions:** Writing reusable code blocks and using built-in functions.
* **Data Structures:** Vectors, matrices, lists, data frames, and factors.
* **Strings:** String manipulation and basic text handling.
* **Input and Output:** Reading data into R and exporting results.
* **Data Manipulation:** Cleaning, filtering, and transforming datasets [Posit Open Source](https://opensource.posit.co/software/tidyverse/ "tidyverse - Posit Open Source").
* **Basic Data Analysis:** Generating summary statistics and exploratory insights.
* **Practice Problems:** Algorithmic challenges and hands-on coding exercises.
